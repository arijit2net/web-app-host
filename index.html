Web Application Host

This repository hosts an HTML file intended for conversion to an Android APK or for embedding within Blogspot pages.

The present content serves as a temporary placeholder. The full application markup can be substituted at any time.

To enable GitHub Pages: open repository Settings, select Pages, set Source to Deploy from a branch, choose main and the root folder, then save.
